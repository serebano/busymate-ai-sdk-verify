# Test vectors

`actor-v3.json` is the shared vector set. Every implementation (Node, Deno, Python, PHP, Go) runs all cases in CI.

```
now, issuer, skew_seconds, max_lifetime_seconds   fixed clock and limits
config                                            audience, tenant_id, connector_id, idp the verifier is configured with
jwks                                              public keys the verifier trusts (also in jwks.json)
reasons                                           the reason-code vocabulary
cases[]  { name, description, options?, calls[] }
  options        overrides of config; "idp": null means "do not pin idp"; "tool" turns the tool check on
  calls[]        run in order with ONE shared replay cache per case
    headers      request headers (X-Bmai-Actor or Authorization)
    options?     per-call overrides
    expect       { ok: true, actor: {sub, idp, confirmed, tool, jti, supportSessionId} } | { ok: false, reason }
```

`source` says where the set comes from. `"local"` is generated by `scripts/gen-vectors.mjs` with the TEST keys in `test-keys.private.json` (never used in production). When the identity contract ships its vectors, run `node scripts/sync-vectors.mjs --from <contract vectors file or URL>`; that writes `contract.lock.json` and CI then fails if `actor-v3.json` is edited by hand or differs from the contract (`BMAI_CONTRACT_VECTORS`).

`jwks.json` is also a public demo issuer for the CLI: `identity-check --jwks https://raw.githubusercontent.com/serebano/busymate-ai-sdk-verify/main/vectors/jwks.json`.
